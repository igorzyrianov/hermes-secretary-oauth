Privacy Policy

Effective date: November 9, 2026

Hermes Secretary is a private personal automation agent operated solely by Igor Zyrianov. It is not a public service and has no external users.

Google user data accessed

  • Gmail: read-only search and retrieval of messages requested by the operator.
  • Google Calendar: reading calendars and events, and creating or updating events and their reminders when instructed.
  • Google Drive: searching file metadata and creating files requested by the operator.
  • Google Docs and Sheets: creating documents and spreadsheets requested by the operator, within the limited Drive access granted to the application.

How data is used

Google user data is used only to execute tasks explicitly requested by the operator. It is not used for advertising, profiling, or training public machine-learning models.

Storage and security

Processing occurs on the operator’s local, user-controlled computer. OAuth credentials are encrypted locally and are not published by this website. This website itself does not collect or store Google user data.

Sharing and sale

Google user data is not sold. It is not shared with third parties except when strictly necessary to execute an operator-requested task through Google APIs and the locally configured AI service.

Retention and deletion

The operator controls local retention and may delete local application data at any time. OAuth access can be revoked from the operator’s Google Account connections page.
