Hermes Secretary

Hermes Secretary is a private personal automation agent operated by Igor Zyrianov. It connects to the operator’s own Google Workspace account to assist with authorized email search and reading, calendar events, and selected Drive, Docs, and Sheets workflows.

Private use only. This application is not offered as a public service and does not accept registrations from other users.

Data handling

Google user data is processed on the operator’s local, user-controlled computer for requested tasks. OAuth credentials are encrypted locally. The application does not sell Google user data or use it for advertising.
